1   to make an empty git repository
   git init


2   to push a file/code to git repository to github
    Add it 
    git add filename

    commit it with a message
    git commit -m "message"


    git push origin master


3  to make a fork {github to github} 
   Login to the repository to the person you wanna make a fork 
   select the repo, click on fork and give it a name 
   push create fork.
   Go on your github account and check it.


4  to make a clone {github to local}
   login to your account on github 
   look for the repo you wanna clone 
   open that repo and click on CODE
   copy the https link 
   login to your local machine 
   run 
   git clone https:
   then git add 
   and git commit
